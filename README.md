# NSG Dashboard - Quản Lý Tài Liệu Nội Bộ Tập Đoàn NS Group

Hệ thống quản lý tài liệu nội bộ, hồ sơ doanh nghiệp và trợ lý AI RAG (Retrieval-Augmented Generation) thông minh dành riêng cho Tập đoàn NS Group (Ngọc Sương Group).

## 🚀 Tính năng nổi bật
- **Quản lý Thư mục & Danh mục đa cấp**: Phân cấp Danh mục chính (FNB, Estate, General...) và các Thư mục dự án con.
- **Trình đọc tài liệu PDF & Word (.docx) chuyên nghiệp**: Trích xuất toàn văn, định dạng chuẩn A4.
- **Trợ lý AI RAG (Google Gemini)**: Tra cứu nhanh lịch sử 70 năm, thương hiệu, dự án và toàn bộ tài liệu nội bộ với cơ chế xoay vòng nhiều API Key & Cache phản hồi 0ms.
- **Tối ưu hóa đa thiết bị (Đặc biệt là iPad & Tablet)**: Giao diện Drawer cảm ứng, bố cục co giãn linh hoạt, vùng chạm ngón tay tiêu chuẩn iPadOS.
- **Đồng bộ cơ sở dữ liệu Supabase**: Lưu trữ dữ liệu thực tế, quản lý tài khoản & phân quyền Admin/Nhân sự.

## 🛠️ Cài đặt & Chạy dự án

```bash
# 1. Cài đặt dependencies
npm install

# 2. Khởi chạy môi trường phát triển
npm run dev
```
